# Night Shift Supply — public sample

This directory is a compact, public-safe demonstration of the planning and prompt-compilation method described in the project README. It repackages the fictional **“A Single Egg”** episode and its public channel/canon/series rules; it contains no client material.

## Files

- [`episode-package.md`](episode-package.md) — human-readable four-shot planning package.
- [`manifest.json`](manifest.json) — the same episode as a machine-readable handoff with stable IDs and explicit continuity.

## Source and proof boundary

Source material: [`Night Shift Supply`](https://github.com/ruizmr/minimax-h3-runpod/tree/main/room/10-Channels/Night%20Shift%20Supply), including the public [`A Single Egg`](https://github.com/ruizmr/minimax-h3-runpod/blob/main/room/10-Channels/Night%20Shift%20Supply/Episodes/ep-001-a-single-egg.md) episode.
